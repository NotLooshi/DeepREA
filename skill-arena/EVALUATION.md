# What has been checked

These are internal observations, not a universal skill ranking or an external user study. The underlying research archive stays private; this summary does not make the old benchmark runs publicly reproducible.

| Check | Observation | Limit |
| --- | --- | --- |
| UI tournament | 13 screening arms, 39 working pages across screening and confirmation; browser checks and two blind model confirmation reviews | Synthetic briefs; same-model reviewers; proposed portfolio only |
| Domain-modeling | 18 task executions; all three arms passed six cases each | Ordinary-agent control also passed: no improvement demonstrated |
| Copied-library cleanup | One text-equivalent duplicate archived; test catalog 136 → 135; restoration verified | Filesystem test catalog, not actual agent routing |
| Codex CLI 0.156.1 | Extracted package discovered, disabled/re-enabled through the supported API, and rediscovered in a fresh app-server | Disposable home; no model turns or automatic-routing test |
| Interrupted recovery | A fresh agent restored an eligible file, preserved newer settings and a recovery copy, and left the conflict unresolved; parent checked final bytes | Synthetic recovery fixture |
| Release tooling | Nine cases exercised across Windows and Linux, including private-file exclusion, reproducibility, invalid references, overwrite refusal, symlinks and junctions | Release tooling stays in the development repo; it does not benchmark skill quality |

The UI trial proposed UI/UX Pro Max as the default. Impeccable's overall advantage was below the frozen replacement threshold, while task-specific differences remained. That supports a scoped decision, not an eternal champion or a claim that every other UI skill is redundant.

The distributed instruction package preserves the evaluated tournament rules and adds an executed conflict-safe recovery check. Older trials used the Skill Maid name. Renaming the skill does not expand what those trials establish.

No general uplift, guaranteed savings, calibrated ranking or fully automatic library optimization is claimed. Tokens and comparable total costs were not measured. Keep results tied to source revisions, tasks, models and tools; retest when those change.
