# UICBINS release evaluation

Evaluation date: 28 October 2026. Candidate: standalone 6.4.6-draft.1. This report separates package validity, generated behavior and visual judgment. The final release differs only in its version label when promoted; source hashes are retained in the development manifests.

## Competitive page trial

All five arms received the same Framehouse brief, a fresh context, GPT-5.6-Terra at medium effort and the same installed browser/runtime route. Each could perform its normal internal workflow. This was not a fixed-token or fixed-time contest. Original local artwork and no external assets were brief constraints. The comparison used pinned Taste v2, Impeccable 4.6.0 with its matching cached engine, Emil guidance, Stitch design guidance and UICBINS. Stitch was not the hosted generation service. Vercel guidelines were applied as an audit, not a sixth generator.

All first handoffs passed 27 shared mechanical checks. That did not clear their semantic, scope or visual findings: UICBINS invented shared timing and put mobile link text over artwork; Impeccable/Emil/Stitch introduced unsupported timing; Taste added an unrequested selection interaction and booking-oriented wording. The original results are retained.

A separate anonymous visual review of settled desktop/tablet/phone images placed UICBINS, Impeccable and Emil together in the top tier; Stitch followed, then Taste. The reviewer preferred UICBINS's visual identity and offer comparison, Impeccable's editorial clarity and Emil's restrained card construction. An initial Emil capture caught a fade; equal settled captures corrected the review. This is one review of one sample per arm, not a general league table. No conversion uplift was measured.

The first UICBINS and Impeccable builders reported unavailable independent review after temporary capacity pressure. A second UICBINS attempt used the unchanged skill and same brief, with reviewer capacity reserved. Its reviewer found a mobile heading overflow; the builder repaired it before handoff and the reviewer replayed closure. Parent replay passed 27/27. Content, local-asset, keyboard, motion and final painted-contrast checks passed within the recorded scope. This repeat is reported separately and does not erase the failed first handoff or inherit its blind visual ranking. Some reviewer capture filenames were reused at closure; the initial finding survives in text, but a complete original before/after image pair is not claimed.

## Transfer and reference adaptation

A separate Fieldnotes reading-list app tests search/category intersection, saved-only filtering, save/unsave, focus after disappearing content, reset cancel/confirm, a second transaction and reload reset. It also tests live URL adaptation from Linear without copying its branding, claims or assets. This is a different product task, not another landing-page ranking. Final parent replay passed 25/25 after internal repairs for hidden mobile reading times and focus after removing a saved item while another remained. An apparent reset-focus failure was a premature test assertion; correcting the wait and rerunning the preserved baseline confirmed it already worked. Exact failing source and captures remain preserved. The independent reviewer verified repairs and the corrected wide/narrow reference evidence. This trial included coordinator-authored QA findings before handoff; it is not an unassisted success-rate claim.

## Package and installation

A clean standalone extraction contained 46 files with matching bytes, valid frontmatter and resolved local links. The bundled rendered checker was executed from the extracted package. A project-local `.agents/skills/uicbins` installation was then discovered through an explicit `$uicbins` PLAN invocation in Codex CLI 0.156.1. It loaded the expected version and left the project files unchanged. This does not test implicit activation or other hosts.

The tested environment used Windows, Node 24.14.0 and Chromium with Playwright available. Original material is MIT; retained Taste runtime/library files preserve their MIT license and attribution. Pro is a separate package and is not included in the standalone release.

## Limits

The skill provides a workflow and tools, not protected enforcement. A capable host, actual browser inspection and completed review remain necessary. These small trials do not establish a reliability rate, accessibility conformance, SEO ranking, conversion gains or universal superiority. Public publishing, live-site validation and outreach are separate actions.
